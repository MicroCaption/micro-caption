Add Stream

Bring a live RTMP feed in from OBS or a hardware encoder; we caption it with live ASR and re-stream A/V to YouTube with closed captions embedded (CEA-608/708). Captions are closed — viewers toggle them with the CC button.

⚠ Input limit: 1080p60 max (1920×1080, up to 60 fps). Set your encoder's Output (Scaled) Resolution to 1920×1080 or lower — higher streams are rejected so the real-time re-encode keeps up.
  1. Point OBS / your encoder at MicroCaption
    In OBS → Settings → Stream, set Service: Custom, then:
    Server rtmp://…:1935/live
    Stream Key stream
  2. Paste your YouTube destination
    From YouTube Studio → Go Live → Stream, copy the Stream URL and Stream key:
  3. Go live
    Start streaming in OBS first, then click Start relay. Allow a few seconds for YouTube to detect the captions, then turn on CC on the watch page. A/V is held back ~2.5 s so captions line up with the picture.

Audio extracted server-side via yt-dlp — no third-party APIs.

Embedded SDI audio from the Blackmagic DeckLink — requires Desktop Video driver.
